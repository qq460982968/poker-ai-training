# 扑克牌AI训练系统

## 项目简介

这是一个基于Java的扑克牌游戏AI训练系统。系统通过大量模拟训练，让AI学习如何将手中的9张牌最优地组合成3组（每组3张），以最大化胜率。

## 游戏规则

- **玩家数量**: 4人
- **每人手牌**: 9张
- **组合方式**: 将9张牌分成3组，每组3张
- **胜负判定**: 比较3组牌的总得分，得分最高者获胜

### 牌型（每组3张牌）

1. **皇家同花顺** (Royal Flush): A-K-Q同花顺
2. **同花顺** (Straight Flush): 连续3张同花色
3. **三条** (Three of a Kind): 3张相同点数
4. **同花** (Flush): 3张同花色
5. **顺子** (Straight): 连续3张不同花色
6. **一对** (Pair): 2张相同点数
7. **散牌** (High Card): 无特殊组合

## AI学习机制

### 1. 统计学习方法
- **经验库**: 存储不同牌型组合的历史胜率
- **探索-利用平衡**: 
  - 探索：随机尝试新组合（初始30%）
  - 利用：选择历史胜率最高的组合（70%）
- **动态调整**: 随着训练进行，逐步降低探索率，增加利用

### 2. 评估机制
- **基础得分**: 基于游戏规则计算的牌型得分
- **经验得分**: 基于历史胜率的经验得分
- **综合得分**: 基础得分 × 0.7 + 经验得分 × 0.3

### 3. 学习过程
- 每局游戏后，AI会记录使用的组合和结果
- 更新经验库中的胜率统计
- 随着训练进行，AI逐渐学会最优组合策略

## 使用方法

### 1. 编译项目

```bash
mvn clean compile
```

### 2. 快速测试

```bash
mvn exec:java -Dexec.mainClass="com.pokerai.QuickTest"
```

### 3. 运行训练

```bash
mvn exec:java -Dexec.mainClass="com.pokerai.Main"
```

程序会提示输入：
- **训练局数**: 建议10000-100000局（训练局数越多，AI学习效果越好）
- **报告间隔**: 每多少局报告一次进度（建议1000）

### 4. 打包运行

```bash
mvn clean package
java -jar target/poker-ai-training-1.0.0.jar
```

## 性能优化

- **组合生成**: 使用随机采样方法，每次评估500种组合（而非全部280种组合）
- **经验库**: 使用HashMap快速查询历史经验
- **多线程**: 可以扩展为多线程训练以提高速度

## 扩展功能

### 1. 自定义游戏规则
修改 `GameRules.java` 中的 `evaluateHand()` 方法来自定义牌型规则。

### 2. 调整AI参数
在 `AIPlayer.java` 中调整：
- `explorationRate`: 初始探索率（默认0.3）
- `learningRate`: 学习率（默认0.1）
- 组合评估权重（基础得分vs经验得分）

### 3. 添加更多AI策略
可以创建多个AI玩家，使用不同的学习策略进行对比。

### 4. 保存/加载模型
可以添加序列化功能，保存训练好的AI模型，以便后续使用。

## 技术栈

- **Java 8+**
- **Maven** (构建工具)
- **无外部依赖** (纯Java实现)

## 注意事项

1. 训练局数建议至少10000局，才能看到明显的学习效果
2. 随着训练进行，AI胜率会逐步提升（理论上限约25%，因为是4人游戏）
3. 经验库会随着训练增长，注意内存使用
4. 可以调整组合生成数量（默认500）来平衡性能和效果
